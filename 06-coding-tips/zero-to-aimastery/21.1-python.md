- inheritance

## Day 3 — Collections

---

## Day 4 — Iterators & Generators

Build

- Log File Reader

Instead of

```
lines = file.readlines()
```

use

```
yield
```

Read one line at a time.

You'll finally understand why generators exist.

---

## Day 5 — Modules

Split a project into

```
main.py
database.py
utils.py
models.py
config.py
```

Most beginners never do this.

Professionals do this every day.
