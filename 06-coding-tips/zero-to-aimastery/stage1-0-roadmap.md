# Stage 1 Learning Order

## Phase 0 — Development Environment (1–2 weeks)

These are tools, not subjects. Learn just enough to use them every day.

- Git
- GitHub
- Linux
- Bash
- SSH

Goal:

- Create repositories
- Commit and branch
- Navigate Linux comfortably
- Edit files
- Run programs
- Connect with SSH

**Do not try to master Linux here.** You'll improve naturally over time.

---

## Phase 1 — Mathematical Language + Complexity (2–3 weeks)

These topics train your way of thinking before you dive into algorithms.

### Mathematics

1. Discrete Mathematics (logic, sets, functions, proof techniques)
2. Complexity Analysis (Big O, Big Ω, Big Θ)

These reinforce each other beautifully.

---

## Phase 2 — Core Programming Theory (6–10 weeks)

### Computer Science

Learn in this order:

1. Arrays
2. Linked Lists
3. Stacks
4. Queues
5. Hash Tables
6. Recursion
7. Trees
8. Binary Search Trees
9. Heaps
10. Graphs
11. Tries
12. Union-Find

For **each** structure:

- Learn the theory.
- Implement it from scratch in Python.
- Analyze its complexity.
- Solve several problems using it.

Only then move on.

---

## Phase 3 — Algorithms (8–12 weeks)

Learn algorithms after their supporting data structures.

Suggested order:

1. Searching
    - Binary Search
2. Sorting
    - Insertion
    - Merge
    - Quick
    - Heap
3. Traversal
    - DFS
    - BFS
4. Greedy Algorithms
5. Divide and Conquer
6. Dynamic Programming
7. Shortest Paths
8. Minimum Spanning Trees
9. Topological Sorting
10. Union-Find Applications

Again:

Learn → Implement → Analyze → Solve problems.

---

## Phase 4 — Mathematics (Parallel)

While Phases 2 and 3 are running, study mathematics continuously.

Recommended order:

1. Calculus I
2. Linear Algebra
3. Calculus II
4. Probability
5. Statistics
6. Calculus III
7. Optimization

Why this order?

- Linear algebra is needed early for machine learning.
- Probability should come after some calculus.
- Optimization makes more sense once you know calculus and linear algebra.

---

## Phase 5 — Software Design

Once you've built several medium-sized programs:

- Object-Oriented Design
- SOLID
- Design Patterns (selected)
- Testing
- Refactoring

Now you'll understand _why_ these practices exist instead of memorizing them.

---

## Phase 6 — Modern C++

Now switch languages.

Learn:

1. Syntax differences
2. References
3. Pointers
4. Stack vs Heap
5. RAII
6. STL
7. Templates
8. Move Semantics
9. Smart Pointers
10. Concurrency Basics

Reimplement several data structures in C++.

This is where you'll truly appreciate memory management.

---

## Phase 7 — Docker

By now you've worked on multiple projects.

Docker will solve a real problem for you instead of being an abstract tool.

Learn:

- Images
- Containers
- Volumes
- Dockerfiles
- Compose (basic)

---
