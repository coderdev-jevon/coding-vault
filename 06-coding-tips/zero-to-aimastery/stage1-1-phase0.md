# My recommended learning order

## Week 1

Step 1(4-7 days)

- Linux Journey
- File system
- Bash

Step 2 (2-3 days)

- Git

Step 3 (1-2 days)

- GitHub

Step 4 (1 day)

- SSH

- Basic Bash Scripting

Practice. (2-3 days)

Create repositories.

Commit.

Branch.

Merge.

Repeat.

# 1. Git & GitHub ⭐⭐⭐⭐⭐

## Primary Resource

### The Odin Project Git Path

This is my favorite beginner resource because it teaches Git through actual development instead of isolated commands.

You'll learn:

- Git workflow
- commits
- branches
- merges
- GitHub
- pull requests
- collaboration

---

## Reference (Keep forever)

### Pro Git

This is probably the best Git book ever written.

Don't read it cover to cover.

Whenever you're confused, look it up.

---

## Daily Habit

Every single project:

```
git init
git add
git commit
git push
```

Eventually Git becomes muscle memory.

---

# 2. Linux ⭐⭐⭐⭐⭐

This is the most important tool after Python.

## Primary Resource

### Linux Journey

This is almost perfect.

Short lessons.

Practical.

No fluff.

Topics:

- filesystem
- permissions
- processes
- networking
- shell

Exactly what beginners need.

---

## Secondary Resource

### Red Hat documentation

Red Hat explains Linux concepts extremely well.

# 3. Bash ⭐⭐⭐⭐⭐

## Primary Resource

Continue with Linux Journey.

Its shell lessons are excellent.

---

## Then

Use Bash every day.

Instead of clicking folders:

```
cd
ls
mv
cp
mkdir
find
grep
cat
less
```

Every day.

---

# 4. SSH ⭐⭐⭐⭐☆

SSH is surprisingly small.

Learn:

- generate SSH keys
- copy public key
- GitHub authentication
- ssh config
- remote login

One afternoon is enough.

---

# 5. GitHub ⭐⭐⭐⭐⭐

Don't watch a long course.

Just learn while using it.

Topics:

- repositories
- README
- Issues
- Pull Requests
- Actions (basic)
- Releases
