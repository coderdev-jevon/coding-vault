## * What is a Prompt
It is the art of communication with AI models, clearer and more detailed will result in a better output from AI models.

Think it as assigning a task to a person.

## * Crafting a Great Prompt
1. **Context**, the material to be worked on
2. **Role**
3. **Expectation**, the desired material to be generated

#### ** Prompt to Learn
```
I am [job role] at [company name]. I just started to learn how to use ChatGPT. Can you provide the top 5 prompts for a [job role] using ChatGPT for a wide range of use cases.
```
#### ** Delimiters
Add delimiters like triple quotes to make it clear your statement. For example,
`Please translate the sentence inside triple quotes """..."""`

#### ** Step-by-step Instructions
Give a clear flow of task to AI models and giving an example will be useful.

#### ** Ask GPT to Make You a Prompt
It is possible to ask GPT to make you a prompt for GPT itself.
