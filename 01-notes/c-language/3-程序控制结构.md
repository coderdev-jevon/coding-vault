## ==🔵* Digits as Characters==
---
```c
char ch;
ch = getchar();

if (ch>='0' && ch<='9') 
	putchar(ch);
```

Simple logic: `ch` with `0` and `9` are compared based on order in ASCII letters table.

---
## ==🔵* How `getchar()` and `putchar` work==
---

User input -> Input Buffer -> `getchar()` pulls one character -> Remove character from buffer

## ==🔵* `for` 语句==
---
```c
for (expression1; expression2; expression3) 
{
	statement // sum += i++ -> sum = sum + i, i=i+=
	// sum += ++i -> sum = sum + i + 1, i=i+1
}
```
expression 1 -> variable
	i=1,sum=0`
expression 2 -> `if else` statement, statement executed here
	`i < 5 || j > 8` or `i > 5 && j < 8`
expression 3 -> 增量表达式
	`i++, j++`

#### ==** 3 - Reverse Digits==
```c
#include <stdio.h>

int main()
{
    int n;
    scanf("%d", &n);
    while(n!=0)
    {
        printf("%3d", n%10);
        n = n/10;
    }
}

```
