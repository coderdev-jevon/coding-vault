## * Example 1


```c
#include <stdio.h> // 编译预处理命令
int main() /* 主程序部分，main为程序入口*/
{
	printf("Hello,World!\n") //printf() 为输出函数
}
```

**解释**
1. 编译预处理命令 `Biānyì yù chǔlǐ mìnglìng` =  preprocessor directories
		translator-editor, pretreat, command/order
2. {}  ==花括号==
3. ; 分号，==语句结束符==
4. `// /* */`  ==注释语句== `Zhùshì yǔjù` comment statement

```c
// # works for one line only
/* */ # works for multiple lines
```



## * Example 2

```c
#include <stdio.h>
int main()
{
    int i,n,fa=1;
    scanf("%d",&n);
    for(i=1;i<=n;i++) // 初值为1，终值为n, 步长为1
        fa=fa*i;
    printf("%d\n",fa);
    return 0;
}
```

**解释**
1. `for` statement ==循环语句==

## * Example 3
```c
#include <stdio.h>
int main()
{
    int n,f;
    scanf("%d", &n);
    f = factorial(n);
    printf("%d\n", f);
    return 0;
}


int factorial(int n)
{
    int i,fa=1;
    for(i=1;i<=n;i++)
        fa = fa * i;
    return fa; // 返回函数值
}
```

**解释**
1. `return fa` ==返回函数值==
