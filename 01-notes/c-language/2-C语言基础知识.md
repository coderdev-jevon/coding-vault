## * 三个进制形式
1. ==**十进制数**==：非零的开头，数字可以是0~9
		例如：159，-159
2. ==**八进制数**==：零为开头，数字可以是0~7
		例如：0157， -0157 ->  1 x 8 ^ 2 + 5 x 8 ^ 1 + 7
3. ==**十六进制数**==：以0x（或0X）为开头，数字可以是0~9，A~F（或a~f）-> 10 - 15
		例如：0x159d，-0X159d -> 1 x 16 ^ 2 + 5 x 16 ^ 1 + 9

## ==* 算术运算符==
	+, -, *, /, %, + (正好)，- （负号），++, --

```c
n++ // n = n + 1
++n // also the same

m = ++n // n = n + 1; m = n
m = n++ // m = n; n = n + 1

x = 1;
y = 1;
z = 1;
w = ++x&&++y||++z
// x = 2, y = 2, w = 1, z = 1, z is not executed because or stop if one is true
```

## ==* Odd and Even Logic==

## ==* 条件运算符与表达式==
```c

// give condition if true result A will be executed, if flase, result B will be executed
```

## ==* 位运算符与表达式 （bitwise operators）==

## * ==逗号运算符==
```c

```

<> means to search in the system standard library folders first, while "" means to search in your current project folder first.

#### ==** Division of Integers and Floating Numbers==
```c
91 / 3 // 30, discard decimal place
91.0 / 3 // 30.333.., 3 promoted to double before calculation
91.0 / 3.0 // 30.333.., double
91 / 3.0 // 30.333.., 91 is promoted to double
```
