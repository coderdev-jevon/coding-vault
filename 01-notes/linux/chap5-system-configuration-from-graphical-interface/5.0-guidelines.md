# AI Systems Engineer Perspective

**Don't learn "how to configure Linux through the GUI."**

Learn:

**GUI → recognize it**

**CLI → actually operate the system**

For this chapter, your real priorities are:

1. 🟢 **Networking**
    
2. 🟢 **Package management**
    
3. 🟢 **System configuration concepts**
    
4. 🟡 Date/time
    
5. 🔴 Display/customization
    

This is where your Linux learning starts becoming directly useful for **servers, SSH, cloud, Docker, distributed systems, and AI infrastructure**.
