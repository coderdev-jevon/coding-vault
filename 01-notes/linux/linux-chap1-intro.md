## * What Linux is?
Linux is a free, open-source operating system, just like Windows or macOS. It controls computer hardware, lets software done, and manage all the work. It is widely used on servers, websites, android phones are built on Linux, smart TVs, etc. 
## * Three Major Linux Distribution Families

## * Red Hat Family Systems / Red Hat Enterprise Linux (RHEL)
include `CentOS, CentOS Stream, Fedora, AlmaLinux, Rocky Linux and Oracle Linux`

#### ** Key Facts about RHEL
1. Basic version of CentOS is identical to RHEL
2. CentOS 8 has no more update -> replaced by CentOS 8 Stream
3. Fedora is an upstream testing platform, upstream is like the high source of water, original source everyone builds from.
4. Support hardware, like Intel x86, Arm, Itanium, PowerPC
5. Uses yum package manager to update and remove packages
6. Widely used by enterprises
## * SUSE Family Systems
including openSUSE

#### ** Key Facts about SUSE Family
1. SLES (SUSE Linux Enterprise Server) is upstream for openSUSE LEAP
2. openSUSE is like CentOS Stream for RHEL
3. `RPM-based zypper` package manager
4. `YaST` (Yet another Setup Tool) for system admin purposes
5. SLES is widely use in retail
6. Known for their strong system management tools and stability
## * Debian Family Systems
including Ubuntu and Linux mint

#### ** Key Facts about Debian Family
1. Debian family is upstream for Ubuntu, Ubuntu is upstream for Linux mint and others
2. Debian has a strong focus in stability and ease of use
3. DPKG-based APT package manager
4. Widely used for cloud deployments, put app on online servers (cloud servers) like Google Cloud
5. Ubuntu is built on top of Debian and is GNOME-based but differs visually
