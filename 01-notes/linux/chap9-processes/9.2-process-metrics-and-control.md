## ==* Load Averages==
Tells you how busy your system is.

==It includes:==
1. Running, currently using a CPU
2. Runnable, in queue
3. Uninterruptible sleepers (wait for disk, device)

#### ==** See Load Average==
```bash
uptime
w
top
```

## ==* Interpreting Load Averages==
`load average: 0.45 0.17 0.12`
**For 1 CPU**
- 0.45 (last minute 45% utilized)
- 0.17 (last 5 minutes 17% utilized)
- 0.12 (last 15 minutes 12% utilized)

#### ** Check Number of CPUs
```bash
nproc # number of processors
```

## * Background and Foreground Processes
Terminal jobs are foreground and background. A single terminal can only execute one foreground job at once. For time-wasting job, you run it in the background by:
1. ==`command &`==
2. Run in the foreground -> ==`Ctrl + Z to suspend` -> `bg` to resume== execution in the background -> ==`fg`== to run it back in the foreground

`Ctrl +  C` to terminal a command

## ==* Managing Jobs==
Background jobs is connected to the terminal, if you close the terminal, the job is automatically killed.
```bash
jobs # to check background jobs
jobs -l
```

#### ** but, using `nohup` will be an exception
```bash
nohup sleep 300 & # no hand up, will run in the background even terminal is closed
```

## ==* The `ps` Command (System V Style)==
```bash
ps # processes of current shell
ps -u [user] # processes for specific user
ps -ef # e means every, f means full, every process in detail
ps -eLf # L means lightweight process (thread), all individual threads.
```

## ==** The `ps` Command (BSD Style) - without dashes==
```bash
ps aux # a = all processes, u = user-oriented format
ps axo # x include processes without controlling terminal, o = output format, manually choose which column to print
	ps axo pid,user,cmd
```

## ==* Process Tree==
It shows processes running in the system in the form of a tree diagram
```bash
pstree
```
## ==* `top`==
It displays dynamic view of what system is doing.

==First line of `top`== output is the quick summary of the system activities.

==Second line of `top`== displays number of processes. Comparing total number of processes with load average can give a hint of system capacity. Stopped processes can be used to examine if everything is running correctly or not.

==Third line of `top`==, how CPU is divided between users and kernel
`us`is user, `sy` is kernel, `ni` (nice) is jobs running at low priority, `id` is idle mode (low if load average is high), `wa` is waiting list for I/O, `hi` is hardware, `si` is software, `st` is steal time (taken for other users), stollen from your VM taken for other VMs

==Fourth and fifth line of `top`==, it shows physical memory (RAM) at line 4 and swap space on line 5. If RAM is exhausted, system starts using swap space as extended memory pool, but accessing disk is much slower. 
```bash
top
q # exit
```
