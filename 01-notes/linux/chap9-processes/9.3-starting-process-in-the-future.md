## ==* Scheduling Future Task by `at`==
single execution job
```bash
at TIME
# Type your commands
# Then Ctrl + D to finish input

atq # to check at queue
atrm <job_id> # remove job at "at"
```

## ==* `cron`==
recurring job

`cron` driven by configuration file `/etc/crontab` (`cron table`)
	Configuration file is a text file that stores settings, rules, instructions for a program, like a handbook.

`crontab` can be for system-wide or individual user-based.

Each line of `crontab` composed of `CRON expression` and command.

```bash
crontab -e # edit
crontab -l # list
crontab -r # remove all
```

#### ==** System Wide Crontab==
`minute hour dayofmonth month dayofweek user command`

#### ==** User crontab (`crontab -e`)==
`minute hour dayofmonth month dayofweek command`

#### ==** Example==
```bash
0 2 * * * /home/student/backup.sh # run backup.sh everyday at 02:00
```

## * `anacron`
`anacron` is more often used these days because ==`cron` has a weakness which is if you power off the machine, the schedules job will not run.==

==`anacron` is present to track on jobs that were missed, run it all== with small delays between them to not overload the system.

configuration file: ==`/etc/anacrontab`==


## * `sleep`
`sleep` is needed to wait another system to become ready or it is used to save energy when it is not needed.

```bash
sleep NUMBER[SUFFIX] # suffix can be s m h d, seconds(default) minutes hours days

echo start; sleep 5; echo end # sleep for 5 seconds until completion
```

#### ** ;
==; is a command separator==, it allows you to write multiple commands on one single line.

#### ==** Interactive vs Non-Interactive Program==
Interactive program waits for you type input, while non interactive runs automatically.
