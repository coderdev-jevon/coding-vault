# What I Actually Need to Master

## Linux Fundamentals

-  🟢 Understand what a **Desktop Environment** is
    
-  🟢 Understand **users and sessions**
    
-  🟢 Understand basic **system startup/shutdown**
    
-  🟢 Understand the **Linux filesystem**
    
-  🟢 Navigate files/directories through the **terminal**
    
-  🟢 Search for files through the **terminal**
    
-  🟢 Create and edit files through the **terminal**
    

## Terminal Commands to Learn

-  `pwd` — show current directory
    
-  `ls` — list files/directories
    
-  `cd` — change directory
    
-  `mkdir` — create directory
    
-  `touch` — create file
    
-  `cp` — copy
    
-  `mv` — move/rename
    
-  `rm` — remove
    
-  `cat` — display file contents
    
-  `less` — read files
    
-  `head` — view beginning of file
    
-  `tail` — view end of file
    
-  `find` — search for files
    
-  `which` — locate executable
    
-  `nano` — basic terminal editor

# Priority Rule

> **Do not try to master the GUI.**
> 
> Learn enough to be comfortable using Linux, then shift your attention toward the **CLI, filesystem, permissions, processes, networking, SSH, services, and system administration**.

**Goal:** Become comfortable operating Linux, not become a Linux desktop power user.
