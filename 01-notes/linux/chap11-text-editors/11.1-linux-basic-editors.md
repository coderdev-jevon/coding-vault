## * Overview of Text Editors in Linux

#### ==** Five Text Editors==
 - `nano` (simple)
 - `gedit` (simple)
 - `vi`
 - `emacs`
- `Visual Studio Code` - `code`
		It is integrated

## * `nano` and `gedit`
==`nano` is terminal-based editor.==
```bash
nano filename
```
==`gedit` is graphical editor==

## ==* `gedit`==
==More configurable== than Notepad, also has a wealth of plugins
	Configurable means that it has many options and plugins to modify how it works.

## ==* `vi` and `emacs`==
They have both text and graphical forms. It is said that learning them will make things to be more efficient, but it requires a bit of an effort in learning.
