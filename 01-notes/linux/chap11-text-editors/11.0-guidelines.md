# Chap 11: Text Editors
Date: 2026-09-10

## * What is a Text Editor
It is a software to open and edit plain text files.
## * Why Should I Learn Text Editors
Text editors are core workspaces for AI/ML work. 

## * Objectives
1. Learn how to create and edit files by text editors inside Linux
2. Learn about `nano` as the text-based editor
3. Learn about `gedit` as the graphical editor
4. Learn about `vi` and `emacs` as advanced editors
