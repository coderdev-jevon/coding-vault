## ==* Lesson 1==
Press Esc to enter Normal Mode (Keys will be treated as commands)
```bash
:q! # Exit editor and discard changes
	: # is command line mode
	! # forced quit, discard changes
x # to delete selected character
i # to insert before the cursor
a # to insert after the cursor
vim FILENAME # to start vim from shell prompt
```

## ==* Lesson 2==
```bash
dw # delete a word
d$ # to delete entire sentence
```

==**Operators and Motions**==
	Commands are made of operators and motions
```bash
d # an operator
u # undo last change
U # return line to original state
CTRL + R # to redo commands
```

You can run motions by them own
```bash
# MOTIONS
w # until the start of next word
e # until the end of the current word (keeps the space)
$ # to the end of the line
```

==**Count for Motions**==
```bash
Nw # you can add numbers before motion to specify how many times
0 # to the start of the line
```

```bash
dd # to delete a line
```

==**Command Syntax**==
```bash
[count] command
[count] operator [count] motion
```


## ==* Lesson 3==
`dd` put deleted word inside vim register
```bash
p # put command, put deleted text below the line
r[character] # replace selected character with new character
ce # change operator, delete until end of word, and put you into insert mode
cc # change the whole sentence
```

`c` works the same way as `d`, same motion syntax 

## ==* Lesson 4==
#### ==** Move Command==
```bash
gg # move to start of file
G # move to the end of file
[number]G # move to specific line on the file
CTRL + G # show file location and file status
45| # move to column 45 of that line
```

#### ==** Search Command==
```bash
/[word] # to search forward
?[word] # to search backward
n # to repeat search forward
N # to repeat search backward
CTRL + O # to go back to original position
CTRL + I # to move forward
```

#### ==** Matching Parentheses Search==
```bash
% # move to matching parentheses
```

#### ==** Substitution Command==
```bash
:s/old/new/ # substitute first occurence
:s/old/new/g # susbtitute all occurences in one sentence, g stands for global
:%s/old/new/g # change all of the occurrences, % for every
:%s/old/new/gc # change but with confirmation, c stands for confirm
```


## * Lesson 5
#### ** How to ==Execute External Command==
```bash
:!command
	:!rm FILENAME
```

#### ** How to ==Write Specific Lines to Another File==
```bash
v # for selecting, v stands for visual

# Then click :
:'<,'>w TEST # only works if file doesn't exist
:'<,'>w! TEST # overwrites TEST
```

#### ** ==Retrieving and Merging Files==
```bash
:r # used to retrieve content of another file or output
:r FILENAME
:r !ls # read output from ls command and retrieve it to the file
```


## ** Lesson 6

#### ==** The Open Command==
```bash
o # open line below the cursor and enter insert mode
O # open line above the cursor
```

#### ==** The Append Command==
```bash
a # move cursor after the letter
i # move cursor before the letter
A # move the cursor to the end of the line
```

#### ==** Another Way to Replace==
```bash
R # to replace more than one letter
```

#### ==** Copy and Paste Text==
```bash
y # copy
	yw # copy a word
	yy # copy the whole sentence
p # paste
```

#### ==** Set Option==
```bash
:set ic # to ignore case
:set hls is # hls means higlight search, is means incremental search (live search)

:set noic # remove ignore case option
```
