# Chap 10: Comparing Files and File Types
Date: 2026-08-27

## ==* Comparing Files with `diff`==
`diff` used to compare files and directories.
```bash
diff file1.txt file2.txt 
```

**Purpose**: Check for updates, adjustments
**Useful Options**: `-c, -r, -i, -w, -q`


## ==* `diff3`==
compares three files at once
```bash
diff3 original_file first_changed_copy second_changed_copy
```

## ==* Patching a File==
Modifications to source code are distributed utilizing patches
```bash
diff -Nur originaldir newdir > patchfile
diff -Nu originalfile newfile > patchfile 
```

==**Patch file**==, this compares old file and new file, and only writes change instructions.

```bash
patch -p1 < patchfile
patch originalfile patchfile
```

## * Using the file Utility
Linux does not trust file extensions to know what that file is.

```bash
file filename # To determine the real nature of a file
```
