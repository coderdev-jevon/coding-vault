## * Introduction to Filesystems
"Everything in Linux is a file."

Filesystem in Linux is structured like an inverted tree, start from the root directory (/).

## * Filesystem Varieties
**Filesystem** is the way your disk organizes files and folders.

==Linux support filesystem types such as== `ext3, ext4, squashfs, btrfs`, also offers implementations used by other OS, such as `Windows, SGI, IBM, MacOS`, also `FAT`

Linux also make use of ==network or distributed filesystems==, where the filesystem mostly on external machines.

## ==* Linux Partitions==
Partitions allow the user to organize contents of disks according to the kind and use of the data contained.

With this kind of isolation, if one partition is exhausted, it will not affect the system to operate.

You can find errors or failures more easily with this kind of organizing contents.

## * Mount Points
Mount a filesystem onto filesystem tree at a mount point before you can start using it.

## * Mounting and Unmounting
`/, /home, /usr` -> mount points (folders)
`/dev/sda1, /dev/sda2` -> partitions (device nodes)
	**Partitions** are pieces of cake from whole hard disk.

Node is an entry inside filesystem, it represents file, folder, link, or hardware device tracked by `inodes`.
	An entry is just one item listed inside a folder.

#### ==** `mount` Command==

```bash
sudo mount [partition] [mountpoint]
```
`/home` shows files stored inside `/dev/sda1`
#### ==** `umount` Command==
to unmount the partition
```bash
sudo umount /home
```
`/home` becomes the original empty base folder

#### ==** How to save Mount State even after Reboot==
Usually, if you mount manually by `mount` command, if will not last in the next reboot.

So, you need to edit `/etc/fstab`, file system table

==Run `man fstab` to read manual page to edit the entries==

#### ==** Look at Mounted Filesystem Information==
```bash
df -Th # T means print type, h means human readable
```

==`tmpfs`== is temporary filesystem stored in RAM, not hard disk, it is not real partition, use for temporary runtime data.


## ==* NFS and Network Filesystems==
A network / distributed filesystem may have all of its data on one machine and spread it out on more than one network node.

==Network filesystem is a shared system== that links different filesystems together (client's filesystem and server's filesystem).

==Many user's home directories are mounted on a server== to let them all access the same files and configuration files across multiple client systems.

Example of Network Filesystems are NFS (the Network Filesystem) by Sun Microsystems and CIFS (SAMBA).

## ==* NFS on the Server==
A daemon is a background program that always wait idle for request, so it can listen your request 24/7.

NFS daemons are like shop staff, this command open the shop and get staff ready to serve.
```bash
sudo systemctl start nfs # to turn NFS on, launch all required NFS daemons
```

==`/etc/exports`== is stored on NFS server (machine), it is a configuration file which tells the server which folder to share, which clients can connect, and what permissions do they have.

```bash
/projects *.example.com(rw)
# folder to share is /projects, clients allowed are all computers with hostname ends with .example.com, permission is read and write
```

#### ** How to make Linux Computer become NFS Server
```bash
sudo apt update
sudo apt install nfs-kernel-server

# Start
sudo systemctl start nfs-kernel-server

# or auto start after reboot
sudo systemctl enable nfs-kernel-server

# check status
sudo systemctl status nfs-kernel-server

# Create folder to share
sudo mkdir -p /srv/my_share
sudo chmod 777 /srv/my_share

# Edit /etc/exports
sudo nano /etc/exports

# Add this to end of line, then Ctrl O, Enter, Ctrl X
/srv/my_share  *(rw,no_subtree_check)

# Load new sharin rule
sudo exportfs -r

# Verify what's being shared
shwomount -e localhost

```

Then, edit `/etc/exports` to set which folder to share, then apply configuration 

#### ** Handle Errors during Installing a Package
There is always error message when error occurred, you must based on it to solve the problem
```bash
sudo apt remove --purge nfs-common libsnfsidmap1 # remove main program
sudo apt autoremove # remove dependencies
sudo apt clean # delete alldownloaded `.deb` files from cache

sudo apt dist-upgrade # distribute upgrade, can add/remove packages to fix dependencies
```

## ==* Exploring Mounted Filesystems==
#### ==** `mount`==
This reads raw data from `/proc/mounts`, show everything what's mounted right now in human-readable output.

#### ==** `cat /etc/fstab`==
It is configuration file. It is like wish-list for boot time, not live status.

#### ==** `cat /proc/mmounts`==
It is raw, true live data from Linux kernel memory.
